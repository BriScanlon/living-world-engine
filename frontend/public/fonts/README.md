# Map label glyphs

Signed-distance-field glyph ranges for MapLibre symbol labels on the atlas globe, so labels need no external glyph
server. Noto Sans Regular, Medium and Italic; ranges 0-255 (Basic Latin, Latin-1), 256-511 (Latin Extended) and
8192-8447 (General Punctuation: curly quotes, dashes).

Source: https://github.com/protomaps/basemaps-assets (`fonts/`), commit
`028c18f713baecad011301ff7a69acc39bcc2ae7` (2025-10-31). Noto fonts are licensed under the SIL Open Font License
1.1: see `OFL.txt`. To add a script, copy more ranges of the same fonts from that commit.
